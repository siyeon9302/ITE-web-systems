How to Create an HTML File

  1. Open a text editor such as VS Code or Notepad.
  2. Write the basic HTML structure using <!DOCTYPE html> and tags.
  3. Save the file with a .html extension (e.g., index.html).
HTML
HyperText Markup Language — defines the structure and content of a web page.
CSS
Cascading Style Sheets — controls the layout and visual style of the web page.
JavaScript (JS)
A programming language that adds interactivity and logic to web pages.
